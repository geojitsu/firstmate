## Overview

Helm is disabled until the main home contains `config/helm.json`. That file
selects the default GitHub Project board; `data/helm-project-map.json` is the
optional main-home map for per-project destinations.

## Usage

Copy `docs/examples/helm.json.example` to `config/helm.json`, then set
`owner` and `number`. Use `bin/fm-helm-project-map.sh` to manage the map.

## API Reference

### `config/helm.json`

`owner` and positive numeric `number` are required. `dispatch_status` defaults
to `In flight`; `reconcile_interval_hours` defaults to `6`.

### `data/helm-project-map.json`

Version 1 contains `projects` and `nudges`. A project entry's `state` is
`active` or `migrating`; absent entries use the default board.

## Notes

The map is keyed by the exact project identity from a local home's
`data/projects.md`, not by a checkout path. Both the map and move ledger are
mode `0600` local state.
